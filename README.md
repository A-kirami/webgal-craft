WebGAL Craft 是一款为 [WebGAL](https://github.com/OpenWebGAL/WebGAL) 游戏创作者设计的创作工具。它把项目管理、脚本编辑、资源浏览、可视化语句编辑和实时预览放在同一个工作流里，让创作者可以更直接地组织素材、编写演出并检查游戏效果。

## 特性

**轻松创作**

可视化编辑与脚本编辑并行，命令默认值与语句编组减少重复配置，让创作者更快组织演出内容。

**高效工作流**

命令面板、快捷键、资源面板与实时预览串联常用操作，编辑、检查和调整可以在同一工作流中完成。

**安心管理**

本地历史保留场景版本，引擎与模板管理支持项目依赖切换，复杂项目也能更稳妥地维护。

**清晰易用**

界面围绕项目、脚本、资源和预览组织，操作简单易用，让创作者更专注于故事与演出本身。

## 快速上手

> [!IMPORTANT]
> WebGAL Craft 需要 WebGAL `4.6.2` 或以上版本的引擎，可在 [WebGAL Releases](https://github.com/OpenWebGAL/WebGAL/releases) 获取

1. 下载并安装适合你系统的 WebGAL Craft。
2. 打开 WebGAL Craft，在主页安装游戏引擎。
3. 创建新游戏，或导入已有 WebGAL 游戏目录。
4. 进入编辑后，在文本/可视化编辑器、资源面板和预览面板之间完成创作。
